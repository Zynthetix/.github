# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report privately using GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on the affected repository (Security tab → Report a vulnerability).

Include:

- A description of the vulnerability and its impact
- Steps to reproduce
- Affected version(s) or commit, if known

We will acknowledge your report and keep you updated on the fix. Please give us a reasonable window to address the issue before any public disclosure.

## Supported versions

Zynthetix projects are in active development. Security fixes are applied to the latest default branch.
